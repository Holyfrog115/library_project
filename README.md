# Library Project for ODP

This library app allows to enter book's data and add it to the page. Then you can delete it and edit read status of the book.

# Features 

- Enter book's data in the dialog form
- Add book to the library collection
- Edit book's read status by clicking on button
- Delete book's card from library collection by clicking on button
